Tagger Example

New features: drag & drop, bulk paste, validation

  • Reorder: drag a tag with the mouse, or focus it (Tab / arrow keys) and press Space to grab, ←/→ to move, Space to drop, Esc to cancel.
  • Bulk paste: copy text like alpha, beta, gamma or several lines and paste into the input — it is split by commas / semicolons / new lines and de-duplicated.
  • Validation: lowercase tags only and at least 2 characters. Rejected tags stay visible with a red error message but are not saved to the underlying input value.
